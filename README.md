# Gb-browser
💜 GB Browser 1.0
Le navigateur gaming pour R36SX / GB350

GB Browser est un projet de navigateur Internet expérimental conçu pour les consoles portables GB350.

🌐 Fonctionnalités prévues
Recherche Google
YouTube
Wikipédia
GeForce NOW
Favoris
Historique
Navigation au joystick
Interface noire et violette
Démarrage automatique
🎮 Matériel
Console R36SX / GB350
Carte microSD 32 Go
Adaptateur Wi-Fi BrosTrend AX7
📁 Fichiers
index.html : interface principale
style.css : design graphique
controls.js : commandes
README.md : présentation du projet
🚀 Objectif

Transformer la GB350 en mini-console Internet utilisable sans clavier ni souris.

⚠️ Statut

Projet expérimental en développement. La compatibilité Wi-Fi, navigateur et GeForce NOW reste à tester.
